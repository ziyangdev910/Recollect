# 2026-11-25 Agent 日志

## 目标

上一轮把打印排版改为「左上填涂 / 右上信息 / 下方通栏笔记 + 并排 QR」后，用户反馈两道题之间的垂直间距仍然过大，要求减半。

## 改动

| 文件 | 意图 | 关联 |
|---|---|---|
| `core/pagination/.../TemplateGeometry.kt` | `itemSpacingMm` 默认值由 3.0mm 改为 1.5mm（题间距减半）；`itemHeightMm` 继续把该值计入条目高度，分页、打印、回读几何均自动使用新值，无第二处硬编码 | D-07、D-08 |
| `feature/print/.../PrintLayout.kt` | 第二次修正：实测生成 PDF 后发现两道题之间的可见空白主要来自书写区最后一条横线下方的整段预留（约 6.25mm），仅改题间距视觉上几乎无变化。`writingLines` 改为把横线铺到书写行底部、只留 `WRITING_BOTTOM_PADDING_MM = 1.0`，空白主要只剩题间距；书写区高度与 OCR 区域不变 | 2026-11-25 用户要求 |
| `core/pagination/src/test/.../{PagePlannerTest,TemplateGeometryTest}.kt` | 按 1.5mm 重算默认模板下的条目高度、yOffset 与 P-02 恰好填满用例（pageHeight 228 / 内容区 197） | 验收门禁 |
| `feature/print/src/test/.../PrintLayoutTest.kt` | 按 1.5mm 重算条目块高度与相邻题目的 blockTop/笔记/QR 坐标；新增横线位置断言（47.5 + 标题 5 + i×8，最后一条距行底 1mm） | 验收门禁 |
| `docs/specs/pagination.md` | 同步 `itemSpacingMm = 1.5` | 2026-11-25 用户授权回写 |
| `docs/changelog.md`、本日志 | 记录本轮改动与验证 | 工作循环 |

说明：页面排版代码（`PrintLayoutBuilder`）不另设题间距常量，条目间距完全由 `PlacedItem.heightMm`（含 `itemSpacingMm`）决定；因此修改 `TemplateGeometry` 的默认值即同时改变打印布局、分页结果与扫描几何投影。

## 验证

- `./gradlew :core:pagination:test :feature:print:test`：通过。
- `./gradlew test verifyCorePurity :app:assembleDebug`：通过。
- 真机 VKJ-AN00 单独运行 `PrintPdfGenerationTest`（`am instrument`，1 个用例通过），拉取生成的 PDF 与 300 DPI PNG 做像素级空白带测量：
  - 修改前：T-1 最后一条书写横线到 T-2 首行之间整幅空白约 7.54mm；
  - 修改后：约 4.23mm，约为原来的 56%（题间距同时由 3mm 降为 1.5mm）。
  - 证据：`evidence/print/spacing-2026-11-25-before/`、`evidence/print/spacing-2026-11-25-after/`（各含 PDF 与两页 PNG）。
- OMR 采样中心与行起点不受影响。

## 未决 / 下轮建议

## 追加：题间距对齐横线节奏，QR 组合贴最后一条横线

用户反馈上一轮把空白减到约 4.2mm 后太小，要求：题间距改为「复习笔记两条横线之间的距离」，并把 QR-pageId 组合与最后一条横线水平对齐。

### 改动

- `TemplateGeometry`：新增 `noteWritingLineCount = 3`、`noteWritingBottomPaddingMm = 1.0`，派生 `noteWritingLineStepMm`（8mm）、`noteWritingLineOffsetsMm`（13/21/29mm）、`lastNoteWritingLineOffsetMm`、`noteQrTopOffsetMm`（29 − 24 = 5mm）；`itemSpacingMm` 设为 5mm（含横线底部 1mm 与下一题文字行内居中约 2mm，可见空白约 8mm）。
- `PrintLayout`：书写横线直接使用模板的横线偏移；QR + pageId 标签组合改为**底边贴最后一条横线**（不再在笔记行内垂直居中）。
- 单测：默认模板下的条目高度、yOffset、QR/标签坐标全部按 5mm 题间距与 8mm 横线间距重算；新增「QR 组合底边 = 最后一条横线」「最后一条横线 = 行底 − 1mm」等断言。

### 验证

- `./gradlew :core:pagination:test :feature:print:test`、`./gradlew test verifyCorePurity :app:assembleDebug` 通过。
- 真机 `PrintPdfGenerationTest` 通过，生成 PDF 并做像素测量：
  - 笔记横线间距：约 8.0mm；
  - 最后一条横线到下一题首行文字：约 7.8mm（≈ 一条横线间距）；
  - T-1 的 pageId 标签底边与最后一条横线同在 y≈903px（300 DPI），水平对齐。
  - 证据：`evidence/print/spacing-2026-11-25-final/`。
