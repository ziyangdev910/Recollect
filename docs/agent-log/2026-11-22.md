# 2026-11-22 代理日志：本周计划单例与打印快照保护（C-097）

## 目标

- 打印过本周计划后，再次点击首页“生成并打印本周计划”不得静默生成新计划号、覆盖 `Question.pageId/qrPayload`。
- 本周已有计划时复用同一 `planId`；只有用户显式“重新生成本周计划”并确认后才生成新计划，并把旧计划标记为已替代。
- 打印确认只为当前计划写快照；旧计划不得覆盖最新快照。

## 方案（用户批准）

schema v8 计划头 + `PlanSession` 复用/显式重新生成 + 打印快照写入守卫。

## 改动

| 文件 | 意图 |

## 验证

- `./gradlew test verifyCorePurity :app:assembleDebug` → `BUILD SUCCESSFUL`。
- 新增单测：
  - `PlanRepositoryTransactionTest`：计划头写入、显式替代旧计划、快照只写当前计划并标记 PRINTED、旧计划负例。
  - `PlanSessionTest`：有当前计划时 `open` 不调用生成器；无计划才生成；`regenerate` 传入旧计划号。
  - `LoadPlanUseCaseTest`：按冻结元数据重建页/题/附件；缺元数据拒绝。
  - `PrintPlanViewModelTest`：IGNORED_NOT_ACTIVE 时不提示“已记录”。
- 实体机 VKJ-AN00（Android 16）：
  1. 安装后 schema 迁移到 v8；首页显示“生成本周计划”。
  2. 生成 `192512`；返回首页显示“查看并打印本周计划”，再次进入仍为 `192512`。
  3. 预览页“重新生成本周计划”→ 确认 → `NBPCB6`。
  4. 打印 `NBPCB6` 并确认“已打印”，App 显示“已记录本次打印。”。
  5. 拉取 DB（`evidence/db/planreuse-recollect.db`）：
     - `192512` status=`SUPERSEDED`，supersededBy=`NBPCB6`；
     - `NBPCB6` status=`PRINTED`，printedAt 已写；
     - 4 道题 `Question.pageId` 前缀为 `NBPCB6`。
  6. 强停重开：首页仍显示“查看并打印本周计划”，进入预览仍为 `NBPCB6`（`LoadPlanUseCase` 从 DB 重建）。
- 证据：`evidence/screens/planreuse-01…10`、`evidence/ui/planreuse-*`、`evidence/db/planreuse-recollect.db*`。

## 未决 / 风险

- 旧 SUPERSEDED 计划的页面仍可通过 QR 回读并提交反馈；若用户同时扫描新旧两稿可能重复计数。是否在扫描/确认链路拒绝 SUPERSEDED 计划，需要产品决定（C-097 已记录）。
- 迁移不回填历史 `plan_page`；升级前的计划不会被“复用”，但旧纸仍可按 pageId 回读。
- `LoadPlanUseCase` 的预览警告为空：重载已有计划时不再显示生成当时的 overflow 警告。
- R-01 真实纸张回读仍未执行。
