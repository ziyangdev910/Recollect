### `hasNoteArea=false` 的现状（代码与规格事实，未改行为）

- 高度公式：`rightBottom = if (hasNoteArea) noteAreaBaseHeightMm + attachmentArea else 0.0`。为 `false` 时，笔记书写区基础高度与全部附加面积都不计入整题高度。
- 默认模板（`noteAreaBase=30`、每条附件 10、`usable=273`）下，1 知识点 / 1 行的题目：`hasNoteArea=true` 且无附件时 68.5mm；`false` 时 38.5mm，少 30mm；附件的 10/20/30mm 也不再计入。
- 附加上限为 `maxAttachmentHeightMm = usableHeightMm × maxAttachmentHeightRatio`，默认 `273 × 0.30 = 81.9mm`，只约束附加面积本身（不是整个笔记区）；超过时整条移出打印，不截断。
- 现行实现无论 `hasNoteArea` 真假都判定附加上限（规格对上限规则未挂条件）。因此“无笔记区 + 附件面积超限”的题目会被整题移出，尽管它的高度已不含附加区。
- 对页面的影响：不打印笔记区使单题高度最多减少 `noteAreaBase + attachmentArea`，每页能放更多题、续下页标记与页数减少；若附加上限仍生效，则上述“变矮”的题可能反而整题消失，该日条目全部消失时不建页（C-060）。

### C-066：“拆分题目”是什么意思（供人类裁决）

- **拆分题目** = 把一道题拆成两道或多道独立题目（例如把 3 拆成 3a、3b）：每道题有自己的题号、QR、知识点关联（每道 ≤4 个）与预估时长，分别参与调度和填涂。这样每道题的高度都能回到单页内容区以内。
- **不是**把一道题的内容分到两页：分页器从不跨页拆分条目，D-08 明确“整条移至下页，绝不拆分”。
- **不是**拆知识点：知识点是调度单元；拆题时可以把部分知识点关联移到新题上，但知识点本身不拆。
- **适用**：题目过高是因为关联知识点太多或右上名称行数太多（4 个知识点/4 行已用满）；此时“减少附加笔记”通常无效。
- **不适用**：一道不可分割的题（如一篇阅读带多个小问但用户不想拆）；那只能减少知识点关联、调整附加笔记，或接受它进入 overflow、不打印。
- **方案 A** 的文案会把“拆分题目”放在首位，减少附加笔记降为次选；**方案 C** 还会给出量化差额（如“至少还需减少 10mm，或拆成两题”）。
- 本轮未改 C-066 的文案与状态；等待人类在 A/B/C 中裁决。
