# 录入规格（feature/entry）

关联决策：D-06、D-12
关联裁决：C-026、C-028

## 冻结决策（D-06、D-12）

- **D-06**：手写笔记 OCR 只存储和展示，不参与调度；原始 OCR 只读、修正文本可编辑；导出两者都含。
- **D-12**：单题关联知识点 ≤ 4；知识点编号全局唯一不复用；超出 4 个时录入层拦截并提示拆分；录入层与 Repository 双重校验。

## 职责

- 题目录入、知识点录入/编辑、题目与知识点的关联选择。
- 题目录入包含 `estimatedReviewMinutes`（预估复习分钟数），默认 15，允许用户修改；调度时间装箱直接读取该字段（C-017）。**2026-11-28 用户要求**：录入抽屉中「复习时长」文本框位于「第Y题」右侧，只接受数字；有效范围为 1～240 分钟（`EntryDraft.MAX_REVIEW_MINUTES`），为空、0 或大于 240 时显示「复习时长需在 1～240 分钟之间。」并禁用保存；状态层保存前再次校验同样范围。
- 题目来源页码由两部分组成：编号 `sourcePageCode`（最小 1，保存后不自增）与用户单选来源标签 `sourcePage`（如「作业本」「同步练习」，可留空）。同一页的多道题共用同一编号。展示与打印格式为 `编号-来源`；来源为空时只显示编号，不输出 `-`。来源页码用于定位题目在试卷或作业本的哪一面，**不是**复习打印稿的 `pageId`。旧库迁移保留原文本为来源，并按创建时间补 1..N 编号（2026-11-20 用户要求）。
- **页码字段（2026-11-28 用户要求）**：录入抽屉中的页码是一个始终可编辑的紧凑圆角文本框（数字键盘、过滤非数字、最多 5 位），不再区分「试卷编号 / 页码编号」标题，也不再提供只读 +/− 模式；未选来源时标题为「第X份试卷」，选中来源后为「第X页」。`sourcePageCode` 的字段语义与默认值记忆不变；无来源时题目名称按试卷口径显示为「第X份试卷 第Y题」。输入为空或小于 1 时显示「请填写不小于 1 的页码。」并禁用保存。
  - **分别记忆默认值**：无来源取「最近一条无来源题目」的编号，有来源取「最近一条有来源题目」的编号，两者互不影响；无数据时为 1。新建时在「有无来源」之间切换，若用户尚未手动改过编号，自动套用对应类的默认值；用户手改后不再覆盖。编辑既有题目时保留原编号，不因切换来源而重置。
- **来源（2026-11-28 用户要求）**：抽屉中的「来源」与「科目」并排，默认显示当前来源或「未选择（来自试卷）」，点开后在并排行下方整行展开来源小卡片（单选，可空；再次点击已选标签可取消）。「管理来源」常驻在该选择框内、展开箭头的左侧，点击打开全屏来源标签库窗口增删改查（窗口不进入返回栈，关闭后保留未保存的表单内容）。题目仍只保存标签名称；重命名在事务内同步更新题目引用，删除前校验未被未归档题目引用。旧题目中不在标签库的自由文本来源，在编辑时以临时标签展示，可保留或改选。
- **来源标签库（2026-11-22 用户要求）**：`source_tag`（schema v9）保存 `id/name/createdAt`，`name` 唯一。列表按名称升序并附带未归档题目引用数；支持新增、重命名、删除确认（2026-11-24 用户要求删去搜索框）。迁移 v8→v9 时把已有 `question.sourcePage` 去重种入标签库（空白不种入）。
- **知识点分类与录入抽屉的「科目」（2026-11-23 / 2026-11-28 用户要求）**：知识点之上增加一层分类（`knowledge_category`，schema v13）。默认 11 个分类「语文、数学、英语、物理、化学、生物、政治、历史、地理、信息技术、通用技术」，可增删改；新增知识点必须指定分类，编辑知识点可修改分类。「知识点」页继续使用横向分类筛选选项卡；录入抽屉则把分类呈现为「科目」选择行：与「来源」并排，选中后以该分类在主页卡片上的同款纸张底色显示，点开后在并排行下方整行展开分类小卡片。未选科目时不预选任何分类，也不提供「全部科目」选项；再次点击已选科目即清除筛选。切换科目后知识点选项只显示该分类下的知识点，并移除已选中但不属于新科目的知识点。科目只是知识点的筛选入口，不单独持久化；题目所属分类仍由关联知识点推导。
- 知识点编号由 Repository 统一分配，录入层不得自行生成或修改 `number`。
- 手写笔记/附件录入：原始 OCR 只读、修正文本可编辑（D-06）；附件文本写入 `NoteAttachmentItem.text` 时取 `correctedText` 快照。

## 单题关联知识点上限（D-12 / C-028）

- 上限 4 个；0 或负数不允许。
- **双重校验**：
  1. **录入层（UI/ViewModel）**：选择第 5 个时不允许加入，显示「单题最多关联 4 个知识点，请拆分为多道题目」；保存按钮禁用。
  2. **Repository（事务内）**：`QuestionRepository.create/update` 再次校验；超过 4 个或关联到不存在/已作废的知识点时抛 `InvalidKnowledgePointLinkException`，整个事务回滚。
- 调度器 `S-10` 的 `IllegalArgumentException` 是最后一道防线，不是用户可用的拦截。
- 不允许把「超过 4 个」静默截断为前 4 个。

## 知识点编号（D-12 / C-028）

- `KnowledgePoint.number` 全局唯一、创建后不可变、不复用。
- 分配流程（单事务）：
  1. 读取 `KnowledgeNumberSequence` 单行；若不存在（新库/旧库/导入异常），先种入 `(id = 1, lastIssued = max(现有 number, 墓碑 number, 0))`；
  2. `next = lastIssued + 1`；
  3. 若 `next` 命中 `KnowledgePointTombstone.number`，继续 +1（墓碑存在的意义就是阻止复用）；
  4. 写回 `lastIssued = next`；
  5. 插入 `KnowledgePoint(number = next)`。
- 唯一索引 `knowledge_point.number` 是最终约束；并发创建时由事务 + 唯一索引共同保证，不依赖内存计数。
- 删除知识点：先写 `KnowledgePointTombstone(number, knowledgePointId, voidedAt, reason)`，再删除实体；墓碑不随知识点删除而删除。
- 墓碑字段：编号、原知识点 ID、作废时间、原因（`deleted` / `import-conflict` / 其他）。墓碑不是「已删除知识点」的完整副本，只保留编号归属与作废审计。
- 导入时不得重置 `lastIssued` 到较小值；按 `backup.md` 规则校正为最大值。

## 知识点分类（2026-11-23 用户要求）

- 分类字段：`KnowledgePoint.categoryId`（必填，指向存在的 `KnowledgeCategory`）；分类按 `name` 唯一、按 `createdAt` 展示，默认分类在空库创建与 v12→v13 迁移时按给定顺序种入。
- 新增知识点：对话框必须选择分类（名称 + 「分类（必选）」）；无分类时提示先到首页「添加分类」创建，保存按钮禁用。Repository 在事务内复核分类存在，否则拒绝。
- 编辑知识点：可同时修改名称与分类；分类变更不影响 `number` 与已打印计划的行序。
- 分类管理（2026-11-27 用户要求）：删除「知识点」页的「管理分类」入口；分类的新增与封面编辑改由首页「添加分类」/长按进入编辑态后的卡片笔按钮完成，重命名在编辑页的名称字段保存；长按卡片直接进入抖动 + 拖拽排序（不再弹长按菜单），顺序写入 `sortOrder`（schema v16）；编辑态卡片右上角的红叉按钮在分类题目数为 0 时弹紧凑确认浮窗后调用 Repository 删除，题目数大于 0 时只提示不可删除；仓储仍拒绝仍有知识点的分类，删除失败的提示以纯文字 Toast 展示；打开「编辑封面 / 添加分类」页时首页保持在下方组合并继续抖动；封面页作为覆盖整个应用的全屏新页面打开（自带状态栏内边距，顶栏不收起，进入/返回时内容不位移），关闭或保存返回时首页原样露出，不会重建编辑态或出现展示态闪帧，同时重读分类使封面/名称等修改立即显示；离开首页去其他页面才退出编辑。
- 分类筛选：`KnowledgeCategoryFilterRow` 横向选项卡（首项「全部」+ 各分类）在「知识点」页置于顶部（「共 N 个标签」与「新增标签」按钮之上，2026-11-24 用户要求删去搜索框后上移），在录入页置于「知识点标签」标题下，并在筛选卡与标签条目之间绘制分割线，明确「上方是筛选项、下方是条目」；切换分类后标签列表只显示该分类下的知识点，空时显示提示。

## 添加分类页（2026-11-27 用户要求）

- 首页末尾的「添加分类」卡片进入独立页面（`AppRoute.CategoryCreate`），不再跳到「知识点」页。
- 页面参照 `reference/CardEditWindow.png`：顶部关闭与「创建」，中部为所选封面的实时预览（名称、0 道题、淡色提示图标），下方填写「学习本名称」，再从「选择封面」的 4 列网格中选择封面。
- 选择封面由 12 组常用纸张底色 + 提示图标组成（书本、计算器、翻译、闪电、烧瓶、叶片、建筑、时钟、地球、电脑、扳手、通用书本）。不提供「我的封面」与「上传封面」。
- 创建成功后把选中的 `coverTone`（0..5）与 `coverIcon`（稳定字符串 key）写入 `knowledge_category`（schema v15），并返回首页；首页错题本卡片按所选封面渲染。旧分类的封面为 null，仍按分类名称派生图标与底色。
- 首页长按分类卡片的「编辑封面」复用同一页面：预填名称与封面，右上按钮为「保存」，保存时调用 `updateDetails` 同步名称与封面。
- 页面收紧预览与间距，首屏至少显示两行封面；封面格中的小图标位于卡片右下角，与首页卡片一致。
- 名称为空时「创建」禁用；重名沿用 Repository 的 `KnowledgeCategoryNameConflictException`，在名称输入框下方展示错误。

## 题库/知识点编辑

- **列表顺序（2026-11-24 用户要求）**：题库与知识点标签库按用户修改时间倒序展示（`Question.updatedAt` / `KnowledgePoint.updatedAt`，schema v14）。新建或编辑后条目的修改时间刷新为当前时间，因此立即出现在列表最前；时间相同时题库保持插入顺序、知识点按 `number` 升序兜底。复习调度、打印快照、归档、关联计数等系统写回不改变 `updatedAt`，不会打乱用户正在浏览的顺序。迁移时旧数据回填 `updatedAt = createdAt`；旧备份缺少该字段时导入同样回退为 `createdAt`。排序只影响列表展示，不改变 Repository 的归档过滤、计划候选与打印行序（仍按 `number`）。
- 编辑知识点名称不影响 `number`，也不影响已打印计划的行序（行序按 `number` 排序）；编辑知识点分类同理。
- 修改题目关联知识点后，已打印的旧计划稿失效；录入层提示「该题已打印过旧计划，修改关联后请重新生成计划并打印」。
- 归档/取消归档属于 `Question.archived`；归档退出调度，历史反馈保留（D-11）。

## 错题本页面（2026-11-27 用户要求，按 reference/EntryWindow.png 重做）

- **入口与筛选范围**：首页每个知识点分类卡片进入一个错题本（`AppRoute.Entry(categoryId, categoryName)`）；`categoryId = null` 为「全部错题」。题目只要关联了该分类下的任一知识点，就出现在该错题本中（一题可属于多个分类）。
- **列表排序（2026-11-28 用户要求）**：删除「全部错题 / 知识分类」选项卡及「今天 / 昨天 / 更早」分组标签；题目以扁平列表按 `updatedAt`（修改时间）倒序或正序排列，「最近录入 / 最早录入」切换只原地重排列表（带平滑位移动画），不跳转或重置滚动位置；不再提供按知识点分类分组。
- **临时序号（2026-11-28 用户要求）**：每张题卡右下角以中性色显示「#N」，N 按当前列表从上到下（含搜索、筛选与排序后的结果）从 1 递增；仅用于当次展示，不写入题目数据、不参与排序或打印。
- **筛选条**：「来源」「知识点」「最近录入 / 最早录入」三个胶囊横向可滚动，来源与知识点从当前错题本的题目中去重生成；有筛选或搜索时在胶囊右侧固定显示「清除」；搜索按钮固定在同一行最右侧，点击展开/收起位于筛选行上方的搜索框（2026-11-28 用户要求）。来源与知识点点开时不弹下拉菜单，而是在筛选行下方展开与「添加题目」页一致的标签小卡片（首项「全部来源 / 全部知识点」，选中项显示勾选；来源选中用主色、知识点选中用赭石色），选中后自动收起；时间排序仍使用胶囊下拉。搜索行为与原搜索框一致（题号、来源、知识点，大小写不敏感）。
- **题卡**：两行标题「来源」与「第X页 第Y题」，字号与「复习进度」页的题目卡片一致（16sp `titleMedium`，2026-11-28 用户要求）；下方耗时标签与知识点标签并排；整卡进入编辑，右上「更多」菜单提供「编辑」与「删除（归档）」。
- **底部胶囊栏**：只保留「录入 | 打印」（不再提供「复习」）；「打印」进入「生成计划」页。
- **状态保持**：打开录入/编辑抽屉时复用底层错题本的 ViewModel 与 `LazyListState`，抽屉关闭后保留搜索关键词、筛选条件与滚动位置；切换错题本时重置搜索、筛选与排序。

## 题库增删改查（2026-11-20 用户要求）

- **查**：Entry 列表按 `updatedAt` 倒序展示未归档题目（新建/编辑后立即置顶，2026-11-24 用户要求）；每张卡片的大标题分两行显示来源与「第X页 第Y题」（无来源说明时第一行为「第X份试卷」、第二行为「第Y题」，2026-11-28 用户要求），下方把「X 分钟」耗时标签与知识点标签并排，整卡点击进入编辑；卡片右上「更多」菜单提供「编辑」与「删除（归档）」（2026-11-27 用户要求，取代右侧铅笔/垃圾桶图标）。
- **搜索（2026-11-22 用户要求）**：筛选行最右侧的搜索图标展开搜索框，关键词可匹配题号、来源页码（`编号-说明`，说明为空时只有编号）或任一关联知识点名称；大小写不敏感，输入去除首尾空格。空查询显示全部未归档题目；无匹配时显示「没有匹配的题目。」。搜索只过滤展示列表，不改变 Repository 的归档过滤、排序与计划候选。搜索条件保存在 `EntryViewModel`，进入编辑/新建页再返回不丢失；清空关键词恢复全部题目。
- **列表状态**：抽屉打开期间底层错题本保持组合与滚动位置；保存成功后先以带对勾 Toast 提示「保存成功」，再静默刷新列表数据（不闪回 Loading、不跳回顶部），最后收起抽屉。从 Home「录入题目」打开抽屉并保存后进入该题所属科目的错题本页（优先取显式选择的科目；未选科目时取首个关联知识点按编号升序所属分类；无法解析时回退全部错题页），返回键回到 Home；从错题本「录入」打开抽屉并保存后留在原错题本页并刷新列表（2026-11-24 / 2026-11-28 用户要求）。
- **增**：错题本底部胶囊栏「录入」与主页底部「录入题目」都打开同一个底部抽屉。抽屉吸附在内容区底部、盖住底部悬浮胶囊栏，背景压暗；从上到下依次为：题目卡片实时预览（与错题本列表同款卡片，无「更多」菜单与临时序号）、并排的科目与来源、第X页/第Y题/复习时长三个并排紧凑文本框、位于最下方的知识点；底部中间悬浮「取消 / 保存」胶囊（样式与主页底部胶囊栏一致）。来源未选时来源行显示「未选择（来自试卷）」，页码框显示「第X份试卷」；选中来源后页码框显示「第X页」。点开科目、来源、知识点任一选择行时，在其下方就地展开选项；同一时刻只展开一个。
- **科目预填**：从某个知识分类的错题本点「录入」时，科目自动填写为该分类；从主页「录入题目」打开时不填写科目默认值。科目只作为知识点选项的筛选条件，不写入题目。
- **改**：点击题卡或「更多 → 编辑」复用同一个底部抽屉并回填题号、页码、来源、知识点与复习时长；编辑时若关联知识点同属一个分类，科目显示为该分类。保存覆盖原题。题号、页码、来源、标签、预估分钟在同一事务内更新，按新旧关联重算 `activeQuestionCount/dormant`。已打印过的题目在抽屉内提示旧稿失效（E-08）。
- **删**：在题卡「更多」菜单选择「删除」并二次确认后归档（D-11：题目只归档、不硬删除）；归档题目从错题本列表与调度中退出，历史反馈保留。
- 录入与编辑共用同一抽屉和 `QuestionEditViewModel`；保存失败写入 `QuestionEditViewModel.actionError` 并在抽屉内原地提示。删除失败写入 `EntryViewModel.actionError`，在确认框内展示，不替换题库列表；Repository 对更新再次校验 1～4 个标签与标签存在性。「管理来源」「管理知识点」常驻在对应选择框内、展开箭头左侧，点击打开全屏标签库窗口，关闭后仅刷新候选，已填表单保持不变。
- **抽屉收起方式**：点击「取消」、点击抽屉外的压暗区域或按系统返回键都会收起抽屉；抽屉打开期间按返回键不会退出当前页面。首次演示的还原/跳过也会同时收起抽屉。

## 验收

- `./gradlew :feature:entry:test`（UI 校验）与 `:data:room:test`（Repository 事务）全绿。
- 「双重校验」两条路径各有测试：UI 层阻止 + Repository 拒绝。
- 编号不复用测试必须包含「删除 → 新建」与「导入 → 新建」两种路径。
