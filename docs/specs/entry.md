# 录入规格（feature/entry）

关联决策：D-06、D-12
关联裁决：C-026、C-028

## 冻结决策（D-06、D-12）

- **D-06**：手写笔记 OCR 只存储和展示，不参与调度；原始 OCR 只读、修正文本可编辑；导出两者都含。
- **D-12**：单题关联知识点 ≤ 4；知识点编号全局唯一不复用；超出 4 个时录入层拦截并提示拆分；录入层与 Repository 双重校验。

## 职责

- 题目录入、知识点录入/编辑、题目与知识点的关联选择。
- 题目录入包含 `estimatedReviewMinutes`（预估复习分钟数），默认 15，允许用户修改；调度时间装箱直接读取该字段（C-017）。**2026-11-22 用户要求**：该字段只接受数字，且必须是 `>= 1` 的整数；为空、0 或超出整数范围时显示「预估复习时长必须输入不小于 1 的整数。」并禁用保存。
- 题目来源页码由两部分组成：编号 `sourcePageCode`（最小 1，保存后不自增）与用户单选来源标签 `sourcePage`（如「作业本」「同步练习」，可留空）。同一页的多道题共用同一编号。展示与打印格式为 `编号-来源`；来源为空时只显示编号，不输出 `-`。来源页码用于定位题目在试卷或作业本的哪一面，**不是**复习打印稿的 `pageId`。旧库迁移保留原文本为来源，并按创建时间补 1..N 编号（2026-11-20 用户要求）。
- **编号字段标题随来源切换（2026-11-24 用户要求）**：录入/编辑页的编号输入框，未选来源时标题显示「试卷编号」，选中来源后显示「页码编号」。标题只是文案，`sourcePageCode` 的字段语义、默认值记忆、展示/打印格式与编辑方式均不变；校验提示「请输入不小于 1 的页码编号。」只在已选来源时出现，与标题一致。
- **页码编号的两种编辑方式（2026-11-22 用户要求）**：
  - 已选来源时：编号可直接用数字键盘输入（过滤非数字、最多 5 位）；同时保留 +/− 快捷调整。输入为空或小于 1 时显示「请输入不小于 1 的页码编号。」并禁用保存。
  - 未选来源时：编号只读，仅通过 +/− 调整（最小 1）。
  - **分别记忆默认值**：无来源取「最近一条无来源题目」的编号，有来源取「最近一条有来源题目」的编号，两者互不影响；无数据时为 1。新建页在「有无来源」之间切换时，若用户尚未手动改过编号，自动套用对应类的默认值；用户手改后不再覆盖。编辑既有题目时保留原编号，不因切换来源而重置。
- **来源标签（2026-11-22 用户要求）**：录入/编辑页的「来源（可空）」与知识点一样以单选 FilterChip 填写，点击已选标签可取消选择；候选来自独立的来源标签库，由「管理来源」在录入页内打开全屏窗口增删改查（窗口不进入返回栈，关闭后保留未保存的表单内容）。题目仍只保存标签名称；重命名在事务内同步更新题目引用，删除前校验未被未归档题目引用。旧题目中不在标签库的自由文本来源，在编辑页以临时标签展示，可保留或改选。
- **来源标签库（2026-11-22 用户要求）**：`source_tag`（schema v9）保存 `id/name/createdAt`，`name` 唯一。列表按名称升序并附带未归档题目引用数；支持新增、重命名、删除确认（2026-11-24 用户要求删去搜索框）。迁移 v8→v9 时把已有 `question.sourcePage` 去重种入标签库（空白不种入）。
- **知识点分类（2026-11-23 用户要求）**：知识点之上增加一层分类（`knowledge_category`，schema v13）。默认 11 个分类「语文、数学、英语、物理、化学、生物、政治、历史、地理、信息技术、通用技术」，可增删改；新增知识点必须指定分类，编辑知识点可修改分类。分类筛选同时作用于「知识点」页与「录入题目」的知识点标签区；录入页的筛选选项卡放在「知识点标签」标题下、标签列表上，标签列表只显示当前分类下的知识点（「全部」不过滤）。
- 知识点编号由 Repository 统一分配，录入层不得自行生成或修改 `number`。
- 手写笔记/附件录入：原始 OCR 只读、修正文本可编辑（D-06）；附件文本写入 `NoteAttachmentItem.text` 时取 `correctedText` 快照。

## 单题关联知识点上限（D-12 / C-028）

- 上限 4 个；0 或负数不允许。
- **双重校验**：
  1. **录入层（UI/ViewModel）**：选择第 5 个时不允许加入，显示「单题最多关联 4 个知识点，请拆分为多道题目」；保存按钮禁用。
  2. **Repository（事务内）**：`QuestionRepository.create/update` 再次校验；超过 4 个或关联到不存在/已作废的知识点时抛 `InvalidKnowledgePointLinkException`，整个事务回滚。
- 调度器 `S-10` 的 `IllegalArgumentException` 是最后一道防线，不是用户可用的拦截。
- 不允许把「超过 4 个」静默截断为前 4 个。

## 知识点编号（D-12 / C-028）

- `KnowledgePoint.number` 全局唯一、创建后不可变、不复用。
- 分配流程（单事务）：
  1. 读取 `KnowledgeNumberSequence` 单行；若不存在（新库/旧库/导入异常），先种入 `(id = 1, lastIssued = max(现有 number, 墓碑 number, 0))`；
  2. `next = lastIssued + 1`；
  3. 若 `next` 命中 `KnowledgePointTombstone.number`，继续 +1（墓碑存在的意义就是阻止复用）；
  4. 写回 `lastIssued = next`；
  5. 插入 `KnowledgePoint(number = next)`。
- 唯一索引 `knowledge_point.number` 是最终约束；并发创建时由事务 + 唯一索引共同保证，不依赖内存计数。
- 删除知识点：先写 `KnowledgePointTombstone(number, knowledgePointId, voidedAt, reason)`，再删除实体；墓碑不随知识点删除而删除。
- 墓碑字段：编号、原知识点 ID、作废时间、原因（`deleted` / `import-conflict` / 其他）。墓碑不是「已删除知识点」的完整副本，只保留编号归属与作废审计。
- 导入时不得重置 `lastIssued` 到较小值；按 `backup.md` 规则校正为最大值。

## 知识点分类（2026-11-23 用户要求）

- 分类字段：`KnowledgePoint.categoryId`（必填，指向存在的 `KnowledgeCategory`）；分类按 `name` 唯一、按 `createdAt` 展示，默认分类在空库创建与 v12→v13 迁移时按给定顺序种入。
- 新增知识点：对话框必须选择分类（名称 + 「分类（必选）」）；无分类时提示先到「管理分类」创建，保存按钮禁用。Repository 在事务内复核分类存在，否则拒绝。
- 编辑知识点：可同时修改名称与分类；分类变更不影响 `number` 与已打印计划的行序。
- 分类管理：可在「知识点」页通过「管理分类」新增/重命名/删除；仍有知识点归属的分类不可删除；名称重复时提示。
- 分类筛选：`KnowledgeCategoryFilterRow` 横向选项卡（首项「全部」+ 各分类）在「知识点」页置于顶部（「共 N 个标签」与「新增标签」按钮之上，2026-11-24 用户要求删去搜索框后上移），在录入页置于「知识点标签」标题下，并在筛选卡与标签条目之间绘制分割线，明确「上方是筛选项、下方是条目」；切换分类后标签列表只显示该分类下的知识点，空时显示提示。

## 题库/知识点编辑

- **列表顺序（2026-11-24 用户要求）**：题库与知识点标签库按用户修改时间倒序展示（`Question.updatedAt` / `KnowledgePoint.updatedAt`，schema v14）。新建或编辑后条目的修改时间刷新为当前时间，因此立即出现在列表最前；时间相同时题库保持插入顺序、知识点按 `number` 升序兜底。复习调度、打印快照、归档、关联计数等系统写回不改变 `updatedAt`，不会打乱用户正在浏览的顺序。迁移时旧数据回填 `updatedAt = createdAt`；旧备份缺少该字段时导入同样回退为 `createdAt`。排序只影响列表展示，不改变 Repository 的归档过滤、计划候选与打印行序（仍按 `number`）。
- 编辑知识点名称不影响 `number`，也不影响已打印计划的行序（行序按 `number` 排序）；编辑知识点分类同理。
- 修改题目关联知识点后，已打印的旧计划稿失效；录入层提示「该题已打印过旧计划，修改关联后请重新生成计划并打印」。
- 归档/取消归档属于 `Question.archived`；归档退出调度，历史反馈保留（D-11）。

## 题库增删改查（2026-11-20 用户要求）

- **查**：Entry 列表按 `updatedAt` 倒序展示未归档题目（新建/编辑后立即置顶，2026-11-24 用户要求）；每张卡片的大标题分两行显示来源与「第X页 第Y题」（无来源说明时第一行为「编号X」、第二行为「第Y题」），下方把「X 分钟」耗时标签与知识点标签并排，整卡点击进入编辑；右侧提供「编辑（铅笔）」与「删除（垃圾桶）」图标（2026-11-25 用户要求）。
- **搜索（2026-11-22 用户要求）**：列表顶部提供搜索框，关键词可匹配题号、来源页码（`编号-说明`，说明为空时只有编号）或任一关联知识点名称；大小写不敏感，输入去除首尾空格。空查询显示全部未归档题目；无匹配时显示「没有匹配的题目。」。搜索只过滤展示列表，不改变 Repository 的归档过滤、排序与计划候选。搜索条件保存在 `EntryViewModel`，进入编辑/新建页再返回不丢失；清空关键词恢复全部题目。
- **列表状态**：从编辑/新建页返回时复用同一列表实例与滚动位置，不重新加载、不回到顶部；保存成功后先以带对勾 Toast 提示「保存成功」，再静默更新列表数据（不闪回 Loading）。从 Home「录入题目」进入的新建页保存后不关闭回上一页，而是替换为题库页（返回键回到 Home，2026-11-24 用户要求）。
- **增**：右下角「+ 录入题目」进入独立的录入页面；保存成功后关闭页面回到题库并刷新列表（2026-11-24 用户要求）。
- **改**：点击铅笔进入独立的编辑页面并回填题号、页码编号/来源、标签与预估分钟；保存覆盖原题。题号、页码、来源、标签、预估分钟在同一事务内更新，按新旧关联重算 `activeQuestionCount/dormant`。已打印过的题目在编辑页面提示旧稿失效（E-08）。
- **删**：点击垃圾桶并二次确认后归档（D-11：题目只归档、不硬删除）；归档题目从题库列表与调度中退出，历史反馈保留。
- 录入/编辑页面与列表共用同一套表单字段，但由独立路由承载（`QuestionEdit`）；保存失败写入 `QuestionEditViewModel.actionError` 并原地提示。删除失败写入 `EntryViewModel.actionError`，在确认框内展示，不替换题库列表；Repository 对更新再次校验 1～4 个标签与标签存在性。

## 用例表

| ID | 场景 | 断言 |
|---|---|---|
| E-01 | 关联 1～4 个知识点 | 保存成功，事务提交 |
| E-02 | 选择第 5 个知识点 | UI 拒绝加入并提示拆分；不产生保存调用 |
| E-03 | 绕过 UI 直接调用 Repository 传 5 个 | 抛 `InvalidKnowledgePointLinkException`，事务回滚 |
| E-04 | 新建知识点 | 编号由序列表分配，唯一索引通过 |
| E-05 | 删除知识点后新建 | 新编号跳过墓碑编号，不复用 |
| E-06 | 并发创建两个知识点 | 两个编号不同；无唯一索引冲突未处理异常 |
| E-07 | 修改知识点名称 | `number` 不变；打印行序不变 |
| E-08 | 修改已打印题目的关联知识点 | 提示旧稿失效；不静默沿用旧行序 |
| E-09 | 笔记附件写入 | `NoteAttachmentItem.text` 取 `correctedText`，不取 `rawOcrText` |
| E-10 | 空 `KnowledgeNumberSequence` 表（新库/旧库） | Repository 种入 `lastIssued = max(现有 number, 墓碑 number, 0)`；首个知识点成功编号，不抛空表异常 |
| E-11 | 编辑题目（题号/页码/标签） | 覆盖原题；旧标签引用计数下降、新标签上升；无效关联被 Repository 拒绝 |
| E-12 | 删除题目 | 归档后从列表与调度退出；历史反馈保留；关联标签计数下降 |
| E-13 | 题库搜索 | 题号/来源页/任一知识点命中即展示；大小写不敏感；空查询显示全部；无匹配提示；编辑页返回保留关键词 |
| E-14 | 来源标签增删改查 | 新增去空白且名称唯一；重命名同步更新题目 `sourcePage`；仍被未归档题目引用的标签不能删除；空库/无匹配有提示 |
| E-15 | 录入页单选来源 | 同一时刻最多一个来源被选中；再次点击已选标签清空来源；题目保存后来源为空时页码只显示编号 |
| E-16 | 页码编号按来源切换编辑方式 | 选中来源后可键盘输入且保留 +/−；未选来源时只读、仅 +/−；空/0 禁用保存并提示 |
| E-17 | 页码默认值分别记忆 | 无来源默认取最近一条无来源题目的编号，有来源默认取最近一条有来源题目的编号；新建页切换来源且未手改时自动套用，手改后不覆盖 |
| E-18 | 新增知识点必须指定分类 | 未选分类或无分类时保存禁用；Repository 对不存在/已删除的分类抛异常并回滚；编辑可将知识点改到另一分类 |
| E-19 | 分类筛选与分类管理 | 「全部」显示全部标签，选中分类后两页均只显示该分类标签；分类名唯一；有知识点的分类不可删除，空分类可删除 |

| E-22 | 题库/知识点按修改时间倒序 | 新建或编辑题目/知识点后，该条目立即出现在题库/知识点列表最前；复习调度、打印、归档等系统写回不改变顺序；迁移后旧数据按 `createdAt` 参与倒序（2026-11-24 用户要求） |
| E-23 | 题库题卡展示 | 大标题分两行：来源与「第X页 第Y题」；无来源说明时第一行为「编号X」、第二行为「第Y题」；耗时标签与知识点标签同一行并排，大字号下整体换行；整卡进入编辑（2026-11-25 用户要求） |

## 验收

- `./gradlew :feature:entry:test`（UI 校验）与 `:data:room:test`（Repository 事务）全绿。
- 「双重校验」两条路径各有测试：UI 层阻止 + Repository 拒绝。
- 编号不复用测试必须包含「删除 → 新建」与「导入 → 新建」两种路径。
